# Overview
This is a telegram bot written with telegram bot API to help with checking of bus timing

# Requirements
## Register new bus stop
- The bot allow users to register a new bus stop and put a name tag to it for easier retrieval

## Deregister bus stops
- The bot allow users to list out bus stops and remove it from memory

## Check bus stops arriving bus
- The bot allow users to choose from a list of 'registered' bus stop to display arrival timing of buses
